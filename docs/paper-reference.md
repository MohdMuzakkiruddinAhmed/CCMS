## Abstract

CCMS (Case Count Metric System) provides a ground-truth-free methodology for comparing two entity resolution (ER) clustering outputs. Each cluster from the baseline ER process (ER1) is classified into one of four mutually exclusive cases: Unchanged, Merged, Partitioned, or Overlapping — based on how it was transformed by the second ER process (ER2).
